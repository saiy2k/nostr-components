# Specs

New behavior goes in this directory: what it does, and a `## Seams` section naming the interfaces under test.

Specs that already exist stay beside the component. Like and Zap live in `src/nostr-like-button/spec/` and `src/nostr-zap-button/spec/`. Do not copy them here, and do not invent a spec for behavior that is not part of the change.
