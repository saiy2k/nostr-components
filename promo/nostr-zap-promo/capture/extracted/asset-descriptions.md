# Asset descriptions

No website was captured (no-capture path). Every asset below was authored or
resolved for this project from the product's source code; all are vector.

## Product

- zap-bolt.svg — the extension's exact zap icon: yellow lightning bolt, fill #FFC800, path `M13 2L3 14h7v8l10-12h-7z`, 24x24 viewBox. The hero mark of the whole video.

## Platform logos (official marks via media-use / theSVG)

- x-logo.svg — official X (formerly Twitter) logo, white fill, 1200x1227 viewBox (MIT, thesvg).
- youtube-logo.svg — official YouTube play-button mark, red #FF0000 rounded rectangle with white triangle, 256x180 viewBox (CC0, thesvg).

## Recreated product surfaces (props for the X and YouTube UI reconstructions)

- x-creator-avatar.svg — circular illustrated avatar of the fictional X creator "Mira Okafor" (@miradraws): peach background, dark hair bun, teal sweater. 200x200.
- x-post-artwork.svg — the artwork Mira posts, titled "last light": flat vector sunset over layered purple mountains and a glowing lake, 16:9 (1600x900). Shown as the tweet's attached image.
- yt-video-still.svg — the YouTube video frame for the fictional channel "Nova Loops": flat vector lofi night studio (city skyline and moon through a window, warm lamp, synth keyboard, plant), 16:9 (1920x1080). Shown inside the YouTube player.
- yt-channel-avatar.svg — circular channel avatar for "Nova Loops": purple-to-pink gradient, cream crescent moon, white waveform bars. 200x200.
- ui-icons.svg — icon sheet of `<symbol>`s to copy path data from: X action row (x-reply, x-repost, x-heart, x-heart-filled #F91880, x-views, x-bookmark, x-share), more (three dots), YouTube action row (yt-thumbs-up, yt-thumbs-down, yt-share, yt-download), verified badge (#1D9BF0), zap-bolt (#FFC800), cursor-arrow (white pointer with dark outline). Stroke icons are 24x24, stroke currentColor, width ~1.9, round caps.
